# Portafolio — Angélica Montoya

Portafolio web personal de Angélica Montoya, profesional con perfil tecnológico mixto en desarrollo de software, análisis de datos e inteligencia artificial. Presenta perfil, habilidades, formación, proyectos, terminal interactiva y contacto.

Construido con React + Vite. Todo el contenido vive en `src/data/` y el diseño en `src/components/` + `src/styles/global.css`.

## Ejecutar
Requisitos: Node.js 18+ y Git.
```bash
cd portafolio-angelica
npm install
npm run dev
```
